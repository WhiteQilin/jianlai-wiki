# Contributing to Jian Lai Wiki

Thank you for your interest in contributing to the Jian Lai Wiki! This is a fan-made encyclopedia dedicated to organizing the vast lore of *Sword, Come! (剑来)*.

We welcome contributions from the community to help expand the archive, correct mistakes, and improve the reading experience.

## How to Contribute

Since this wiki is statically generated and does not have a public editing interface, all contributions are managed through GitHub Issues.

### 1. Report an Issue
If you find a typo, broken link, or incorrect lore, please open an issue:
- Go to the [Issues page](https://github.com/WhiteQilin/jianlai-wiki/issues)
- Click "New Issue"
- Describe the problem clearly, including the URL of the page where you found it.

### 2. Suggest an Edit
If you have more details to add to an entry or want to provide better citations:
- Open an issue with the title format: `[Edit Suggestion] Page Name`
- Provide the new content or corrections.
- **Crucial:** Please include volume and chapter numbers (or other source notes) to verify the lore.

### 3. Request a Page
If you notice a missing character, artifact, location, or other lore element:
- Open an issue with the title format: `[Page Request] Entry Name`
- Provide as much detail as you can about the requested entry to help us create it.

## Content Guidelines

When suggesting content, please keep the following in mind:

*   **Preserve Chinese Terms:** Keep original pinyin or characters where useful for context (e.g., Qi Refiner / 练气士).
*   **Cite Sources:** Always try to include volume and chapter numbers when adding new lore.
*   **Avoid Speculation:** Stick to confirmed facts from the novel. Unconfirmed theories should be clearly marked as speculative or avoided entirely.
*   **Match the Style:** Content should follow the existing objective, encyclopedic tone of the wiki. Avoid overly casual language or personal opinions.

## For Developers

If you are a developer and want to contribute code or directly edit the markdown content:

1.  Fork the repository.
2.  Clone your fork locally.
3.  Run `npm install` to install dependencies.
4.  Run `npm run dev` to start the development server.
5.  Make your changes (content is located in the `content/` directory).
6.  Run `npm run editor:qa` to ensure your content changes pass validation.
7.  Submit a Pull Request with a clear description of your changes.

Thank you for helping us build the ultimate Jian Lai archive!
